# Rendering samples

Open these three files side by side after switching to Violet Hour. They cover the
"Done when" checks from the brief:

| File | What to look for |
|---|---|
| `sample.tsx` | italic comments and keywords, italic parameters, JSX intrinsic tags (teal) vs component tags (tan), template-literal `${}` punctuation, regex, decorated numbers |
| `sample.css` | selector / property / value / unit each in a different color |
| `package.json` | keys distinct from string values; numbers and booleans distinct again |

Nothing should render as unstyled default-foreground text.
